A10 (Nairuz's suggestion; Paul's ruling): a common gene set per cell type used at all three levels, with ranks RECOMPUTED within the set (lib/eric_a10.py, lib/eric_subset.py), on Eric's pipeline.
Set(cell type, rule) = genes that passed the existing per-group filters (are in the group's gene set) in >= k of the cell type's datasets (p50, p70, p100 of 7 or 6 datasets), intersected with the genes present in BOTH bulk matrices. Sizes: gene_set_sizes.tsv (e.g. p70: astrocyte 5,129; excitatory 8,863; inhibitory 8,532; microglia 4,040; oligodendrocyte 3,707; opc 5,305).
Each group uses Set ∩ its own genes (group_gene_counts.tsv); xBulk uses Set ∩ bulk genes (bulk_gene_counts.tsv; one bulk network per cell type's set; Pearson across samples recomputed and re-ranked within the set; the bulk matrices were already log2/quantile-normalised over the full bulk gene set and are NOT re-normalised: flagged).
xCell: per-subject Pearson over the set genes, ranks within the set, same aggregation; xSubject: mean CPM -> log2 -> quantile normalisation recomputed over the set genes (CPM library size still over all group genes).
Outputs: results.tsv (all comparisons, 4 thresholds), summary.tsv, summary_by_level.tsv. Edge sets: eric/edges_sub/A10_p50|p70|p100.
Summary at 1% (mean OR; baseline = Eric's full-gene-set results): xCell replicability baseline 37.8 -> p50 40.2, p70 42.7, p100 48.1; xSubject replicability 6.5 -> 6.5, 6.8, 7.8; preservation xCell->xSubject 11.05 -> 11.4, 12.2, 13.5; xBulk replicability (rosmap vs velmeshev, per cell type's set) 42.1 -> 30.2, 30.1, 30.5; xBulk preservation (sc/sbj truth, bulk predicted) 8.5/8.7 -> 3.4/3.5, 3.1/3.2, 3.1/3.1.
Differences vs baseline: (1) the ordering of the levels is unchanged (xCell and xBulk replicate far better than xSubject; xCell edges are preserved in xSubject and xBulk); (2) xCell and xSubject replicability go UP with a stricter common set; (3) xBulk preservation and replicability go DOWN (8.5 -> ~3.1; 42 -> 30), but this is not like-for-like: the baseline bulk network ranks all 21-25k genes while the A10 bulk network ranks only the cell type's 3.7-8.9k genes and the universe shrinks accordingly; (4) preservation in xBulk is weakest for microglia (1.5) and oligodendrocyte/OPC (2.2-2.6), strongest for excitatory (5.5-5.7).
